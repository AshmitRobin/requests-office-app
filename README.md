Requests Office

Requests Office is a full-stack web application built for the Centre for Artificial Intelligence Full Stack Development Internship Assignment.

The goal is to make managing requests across multiple campuses easier by bringing request submission, document handling, reviews, and status tracking into one place.

Features

- Login with separate roles for requesters, coordinators, and specialists.
- Submit requests with details and supporting documents.
- Review requests, manage corrections, and track progress.
- Specialist review and final request closure.
- Activity logs for request-related actions.

Tech Stack

- Frontend: React, Vite
- Backend: Node.js, Express.js
- Database: MySQL
- Authentication: JWT

Live Links

- Application: https://requests-office-app-nu.vercel.app
- Backend API: https://requests-office-app.onrender.com
- GitHub: https://github.com/AshmitRobin/requests-office-app

Run Locally

1. Clone the repository.
2. Install dependencies in both "backend" and "frontend".
3. Configure the database and environment variables.
4. Start the backend using "npm start".
5. Start the frontend using "npm run dev".

Demo accounts are available on the application's login page.
